How it's built

Aether2D is built around two decisions made early and kept consistent everywhere else in the engine: game objects are composed, not inherited, and their data lives in memory the way the CPU actually wants to read it.

Entity Component System

An entity in Aether2D is nothing more than an ID. Everything a game object needs — a position, a sprite, a velocity — is stored as a plain component, and systems are the only place behaviour lives, each one operating over every entity that has the components it cares about.

This keeps a Transform from ever needing to know a Sprite exists, and lets new gameplay features get added as new components and systems, rather than new branches in a growing inheritance tree.

Memory-first design

Components of the same type are stored together in tightly packed arrays, not scattered across individually allocated objects. Iterating every Transform in the game means walking one contiguous block of memory, which is exactly what the CPU cache is built for.

Frequent allocations are routed through custom pool and arena allocators instead of the general-purpose heap, trading a little upfront bookkeeping for predictable frame times and far less allocator overhead during gameplay.

Roadmap

Aether2D is being built in five deliberate stages, starting from a bare window and ending at a 2D physics-driven engine loop.

  1. 01
    Complete

    Setup

    CMake-based build pipeline, a windowing and rendering context, and a logging layer for everything else to build on.

  2. 02
    Complete

    Game Loop

    A fixed-timestep update loop with frame pacing and interpolation, so gameplay stays stable independent of render frame rate.

  3. 03
    In progress

    Asset Manager

    Reference-counted loading for textures and audio, a shared resource cache, and hot-reloading during development.

  4. 04
    Planned

    ECS

    Archetype-based component storage and a system scheduler, replacing the current placeholder object model.

  5. 05
    Planned

    Physics

    2D broad and narrow-phase collision detection with simple rigid body integration, built directly on top of the ECS.
